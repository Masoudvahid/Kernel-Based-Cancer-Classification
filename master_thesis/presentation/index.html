Welcome committee members, supervisor Prof. Oleg Pianykh, and colleagues. I am Masoud Vahid Dastgerdi, and today I will present my Master's thesis: "Optimal Classification of Low-volume Medical Data with Adaptive Kernel Design".

This research focuses on addressing the fundamental sample size and parameter complexity challenges in medical image diagnostics, particularly when applying machine learning to rare conditions or small datasets.

Background & Motivation: The Low-Volume Constraint

⚠️ Core Medical Image Challenges
  • Annotation Scarcity: Expert annotations in mammography are extremely scarce, and patient cohorts are often very small (hundreds, not millions).
  • Deep Learning Overfitting: High-capacity Deep CNNs are prone to massive overfitting in this regime, requiring heavy pre-training or augmentation.
  • Black-Box Transparency: Medical diagnostics require models that are transparent by design, not just explainable post-hoc.
💡 The Proposed Solution

We propose that low-volume medical data is a setting where stronger priors and structured models are highly beneficial, rather than compromises.

By designing Adaptive Kernels, we represent local image tissue details with explicit structural controls, reducing parameters from millions to a handful while preserving classification performance.

In medical imaging, particularly mammography, expert annotations are rare and cohorts are small.

Standard deep learning models have millions of parameters, making them highly prone to overfitting on low-volume datasets without heavy pre-training.

We propose that low-volume data is a setting where stronger priors and structured models are highly beneficial, rather than compromises, and can provide diagnostic transparency by design.

The Proposed Kernel-Bank Pipeline

Our complete kernel-based framework maps convolved textures directly into a lightweight classifier:

Step 01
Patch Extraction
Extracts fixed 128x128 positive (lesion) and negative (background) patches with strict patient separation.
Step 02
Kernel Bank Gen
Builds a diverse library of 2D kernels across 9 filter families (Gabor, Gaussian, LBP-inspired, etc.).
Step 03
Response Pooling
Convolves patches and reduces 2D response maps to scalar features using absolute maximum pooling.
Step 04
Sparse Selection
Uses diversity-aware MMR or ABESS selectors to select the most discriminative subset of filters.
Step 05
Light Classifier
Trains a transparent Logistic Regression or single-layer MLP on the selected response features.

This slide outlines our overall methodology. The pipeline consists of five key steps:

First, patch extraction with strict patient split to avoid data leakage. Second, generating a comprehensive kernel bank covering 9 filter families. Third, response pooling using absolute maximum pooling. Fourth, sparse selection using MMR or ABESS. Fifth, training a transparent classifier like Logistic Regression or a single-layer MLP.

Kernel Bank Design & Response Pooling

🛠️ 9 Filter Families (2D Conv)

Our bank extracts multiscale texture features, texture co-occurrence, and smoothness priors:

  • Gaussian filters
  • Anisotropic Gaussian
  • Difference of Gaussians
  • Laplacian of Gaussian
  • Gabor (texture profiles)
  • HOG-like filters
  • GLCM-like filters
  • LBP-like filters
  • MRF smoothness filters

This structure allows the kernel parameters to contain domain-relevant priors, dramatically improving sample efficiency under low-volume constraints.

🔢 Response Aggregation

We convolve image patch $x$ with kernel $K_j$ and apply absolute maximum pooling to summarize local response:

$$R_j(x) = \operatorname{MaxPool}(|K_j * x|)$$

The resulting patch feature vector is fed directly to a linear classifier:

$$\phi(x) = [R_1(x), R_2(x), \dots, R_m(x)]$$

We created a diverse bank of 2D kernels from 9 filter families, capturing multiscale textures and smoothness priors. This structure introduces strong domain-relevant priors.

To extract features, we convolve each patch and apply absolute max pooling. This summarizes the maximum activation of each filter, resulting in a compact feature vector for the classifier.

Adaptive Selection: MMR vs ABESS

⚖️ Maximal Marginal Relevance (MMR)

Balances filter classification utility with feature redundancy:

$$\operatorname{MMR}(j) = \lambda \operatorname{Rel}(j) - (1-\lambda) \max_{i \in S} \operatorname{Sim}(i, j)$$

Kernel Composition: The "Composition Gap"

🔗 Composing Kernels

We try combining multiple selected kernels into a single composite filter to save feature computations:

$$K_{\text{comp}} = \sum_{i=1}^n w_i K_i$$

The Aggregation Non-Equivalency Gap:

Convolving-then-pooling is mathematically different from convolving-individually-then-pooling. Combining filters pre-pooling aggregates away critical visual signals.

📉 Quantitative Composition Gap
Model Configuration Test AUC Test ACC
Unaggregated Base Bank (3 selected) 0.9239 0.7914
Composite Filter Model (1 kernel) 0.8933 0.8150
Composite grid showing composed filters.

To improve computational efficiency, we experimented with composing multiple filters into a single kernel before convolution.

However, we discovered a "Composition Gap". Because convolving-then-pooling is non-equivalent to convolving-individually-then-pooling, combining filters pre-pooling averages out critical diagnostic signals, dropping the Test AUC from 0.9239 to 0.8933.

Rotational Design: Enforced Symmetries

🔄 Enforced Rotation Invariance

Mammographic lesions display structures that are orientation-independent. We enforce rotation invariance by averaging convolved kernel copies rotated at multiple angles (e.g., every $10^\circ$):

$$K_{\text{RI}} = \frac{1}{36}\sum_{i=0}^{35}\operatorname{rot}(K, 10^\circ \cdot i)$$

This hardcodes physical rotational symmetries directly into the model representation, removing the reliance on synthetic data augmentation.

📉 Robustness vs Discrimination
Rotation sensitivity curves of invariant vs standard models.

Enforcing multi-angle stability (e.g., every $10^\circ$ or right-angles) trades off some discriminative details relative to orientation-aware features.

Since mammographic lesions are orientation-independent, we enforced physical rotation invariance by averaging rotated copies of the kernels—specifically sweeping every 10 degrees (36 orientations) or right-angles (4 orientations).

While this hardcodes stability and removes the need for data augmentation, it introduces a trade-off: enforcing exact stability slightly reduces the model's capacity to capture fine, orientation-aware texture details.

Final Model: Learnable-Radius Radial Kernel

🔬 Differentiable Support & Gate

We define a kernel by concentric ring basis functions $B_r$ and learnable coefficients $f_r$:

$$K(x,y) = \sum_{r=0}^{R} f_r B_r(x,y)$$

• $B_r(x,y)$: Binary mask of concentric ring shell $r$
• $f_r$: Learnable coefficient weighting the $r$-th shell
• $R$: Maximum radial support window

We train with a Signed Top-k Response to capture consistent signed structures:

$$s(x;K) = \frac{1}{k}\sum_{p \in \operatorname{TopK}(|K * x|)} (K * x)_p$$

• $K * x$: 2D convolution response map of patch $x$
• $\operatorname{TopK}(|K * x|)$: Indices $p$ of $k$ largest response magnitudes
• $(K * x)_p$: Actual signed response values at selected indices

A differentiable gate learns the optimal support radius (approx 13.18 shells) while smoothness and curvature penalties regularize the profile.

By allowing signed shell values, the model learns not to act as a simple brightness-averaging filter, yielding Test AUC of 0.9101.

Our final model represents a single kernel using concentric rings with learnable coefficients.

We optimize both the coefficients and the support radius jointly using a differentiable gate. This allows the model to learn not just the weights but the optimal size of the filter (around 13.18 shells), achieving a Test AUC of 0.9101.

🏁 Key Takeaways
  • Low-volume viability: Compact, structured kernels offer robust alternatives to large models when data is scarce.
  • Search Efficiency: Sobol QMC covers parameter space uniformly, boosting base model test AUC by +0.0192.
  • Prior Strength: Radial profiles match circular mammography lesion morphology better than unconstrained templates.
  • Learnable Support: The final learnable-radius radial model optimizes size dynamically, achieving test AUC 0.9101 with a single interpretable filter.

We validated the models using localization heatmaps. Both the selected kernel bank and the Deep CNN focus on the same malignant lesion region, validating that our compact model learns clinically relevant features.

In conclusion, adaptive kernels are highly viable for low-volume settings, Sobol QMC significantly improves parameter search, and learnable radial profiles provide transparent, parameter-efficient diagnostics.
